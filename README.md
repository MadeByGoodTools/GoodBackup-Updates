# Good Backup beta downloads

Good Backup is a desktop app by Good Tools for encrypted, compressed backups to your own Nextcloud. Downloads are published on the [Releases](https://github.com/MadeByGoodTools/GoodBackup-Updates/releases) page.

This is an early beta. Mac has been exercised locally; Windows and Linux still need end-to-end device testing. Keep your existing backup until you have completed and verified a backup and a restore on your computer.

Linux scheduling requires systemd user timers, and secure sign-in requires GNOME Keyring or KWallet.
